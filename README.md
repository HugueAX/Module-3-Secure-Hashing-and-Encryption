# Module-3-Secure-Hashing-and-Encryption

This repo contains two files. 

The first uses a Caesar Cipher to encrypt and decrypt text input by the user. It asks the user for a message to encrypt and an integer that is used to shift each character in the message to create the encrypted message.

The second file generates SHA-256 hashes for strings input by the user and files when given the file path. It uses a directory to ask the user what they want to do and then asks for input depending on their answer.
